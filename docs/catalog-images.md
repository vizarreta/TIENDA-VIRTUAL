# Fotos del catálogo de ejemplo

Estas fotos ilustran los productos de demostración; no constituyen fichas técnicas de artículos reales. Las descripciones se limitan a los rasgos visibles. Para vender artículos reales, sustituir ambos campos por fotos y especificaciones del proveedor.
